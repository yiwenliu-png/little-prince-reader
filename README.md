# 小王子英语精读 · Little Prince Reader

面向小学、初中生的英语原著精读软件原型，第一本原著为 *The Little Prince*。

## 已实现

- 原文精读与中文释义
- 重点单词释义
- 浏览器英文朗读与跟读入口
- 听力、口语、阅读、写作练习入口
- IB 方向探究问题：Perspective、Connection、Reflection
- 学习进度页面
- 响应式设计，支持电脑、平板和手机

## 使用

直接打开 `index.html` 即可体验。也可以在仓库 Settings → Pages 中选择 `main / root` 发布为 GitHub Pages。

## 后续开发

完整章节内容、分级词汇、录音上传、口语识别、学生账号、教师端、班级任务、错题本和学习报告。

当前版本为教学演示原型，使用少量示例内容与模拟进度数据。
